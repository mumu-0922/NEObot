# 500-case Golden Gate contract — 2026-07-24

## Finding

The existing `mm-chat.rag-golden.v1` evaluator is a seven-case synthetic G18
retrieval regression check. It cannot produce promotion evidence because it
does not model human review, frozen corpus identity, split/slice admission,
rank metrics, answer/Citation integrity, Active-vs-Candidate comparison,
Holdout execution, leakage, or context cost.

## Implemented boundary

The legacy seven-case evaluator remains unchanged. A separate promotion path
adds:

- `neo-chat.rag-promotion-golden.v1` with draft/human-reviewed case state,
  reviewer UUID/time, exact 60/20/20 split, critical slices, table-exact cases,
  explicit budgets, a precommitted Holdout run UUID, and canonical
  frozen-content SHA-256;
- `neo-chat.rag-promotion-observations.v1` with independent Active/Candidate
  captures, frozen-corpus and Generation/manifest binding, one shared Holdout
  run, top-50/top-10 evidence, answer scores, Citation IDs, integrity, leakage,
  latency, and context tokens;
- `neo-chat-rag-candidate-gate-report.v1` generated by `cmd/rag-eval`, binding
  the raw SHA-256 of every input and containing Active/Candidate metrics, slice
  comparisons, aggregate improvement, budgets, and integrity;
- a Python activation validator that accepts only the exact closed report,
  finite values, consistent counts/arithmetic, absolute gates, no-regression,
  zero leakage, and 100% Locator/provenance/cell-lineage rates.

## Human-review truth

No production Golden corpus was generated. The checked-in JSON is a one-case
`draft` template and is intentionally promotion-ineligible. Tests synthesize
500 cases only to prove contract behavior and label those fixtures as
synthetic. Production admission still requires real reviewer identities,
timestamps, frozen hash, captures, and the one-shot Holdout.

## Activation state

This work does not execute `generation-activate`. The verified Candidate stays
non-active until a real reviewed corpus and passing report exist and an
operator separately approves activation.
